# 隐私和本地数据

本程序默认在本机运行，不包含遥测、广告追踪或云端账号托管。

- 控制台地址只监听 127.0.0.1，并检查 Host、Origin、请求来源和写入令牌。
- 浏览器使用专用 profile，不读取或拷贝已有 Edge、Chrome、Codex 登录资料。
- profile 包含网站登录状态，应当视为私密资料；不应上传到 GitHub、网盘或反馈附件。
- SQLite 保存设置、草稿、操作状态和事件。问答正文可能涉及个人信息，不宜分享数据库。
- API 密钥由 Windows 当前用户加密保存，不能保证在其他 Windows 用户或电脑上解密；迁移时应重新填写。
- AI 请求只在用户点击测试或生成时发生，请自行确认接口服务商和提交的材料。
- 定时任务仅在程序运行时触发视频任务。个人账号仍由本人登录；验证码和课堂弹题交给本人处理。
- 报告默认不包含密钥和 Cookie，但含课程标题、草稿标题和状态，分享前应检查。

默认数据目录：`%LOCALAPPDATA%\CourseStudyAssistant`。程序没有一键清空数据按钮；备份和删除由用户自行决定。

如怀疑真实密钥已公开，去签发平台撤销并重建。不要把密钥、验证码或密码贴到 Issue 中。
