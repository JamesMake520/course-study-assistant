# 评分细则导入说明

适用版本：0.1.2，2026-11-03。

1. 在学习设置中确认当前课程。演示模式和真实课程的规则分别保存。
2. 打开“评分细则”，粘贴考核要求的原文，或选择 TXT、Markdown、JSON 文件。
3. 点击解析。原文只会进入本机规则草稿，不会立即替换已有规则。
4. 对照原文核对每条规则的任务类型、达标条件、每日时长、计分方式及分值。缺失内容可以手工补齐，不确定的保持空白或“待确认”。
5. 勾选核对确认，再保存。更改任意规则后需要重新确认。
6. 需要复用时导出已保存 JSON。导出的文件包含你填写的原文，请按自己的资料保管。

## 支持的输入

- 复制粘贴的中文评分文字，或 UTF-8（可带 BOM）TXT、Markdown。
- 本工具导出的 JSON 结构。其他平台的任意 JSON 不保证兼容。
- 原文最多 20,000 字，最多 30 条规则，每条证据最多 1,500 字。
- 截图、扫描件与 PDF 暂不直接识别。请先复制文字；无法复制时可手工填写关键条件。

## 如何理解得分

“满 12 个有效学习日得 10 分”与“按完成天数比例折算 10 分”是不同公式，需要按真实课程规则确认。规则没写清楚时，不能自行选一个公式。

每日 25 分钟是有效学习日的条件，单纯累计 12 次启动不能证明达标。提问或回答的发布成功也不必然等于被课程计分。当前版本只导入评分规则，尚未把真实平台完整评分证据接入计算，所以首页的实际/预计得分不会凭空显示为完成。

## 编辑与恢复

页面定期刷新不会覆盖正在编辑的草稿。另一窗口保存了新版本，或当前课程改变时，需要重新载入对应规则再确认。解析或保存失败时，原有已保存版本仍保留。

课程规则、原文和版本保存在本机数据目录的 SQLite 文件中。关闭并重新打开软件后仍可读取。本轮不改变已有的登录、自动任务和问答审阅流程。
